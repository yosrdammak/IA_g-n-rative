# Frontend SmartCampus

Le guide complet (Docker, backend, comptes de test, mode IA et API) se trouve dans [../README.md](../README.md).

Depuis ce dossier : `npm ci`, puis `npm run dev`. Le proxy `/api` cible `http://localhost:8001` par défaut. Avec Docker Compose, il cible le service `backend` sur le réseau interne.
